Arsitektur Cepat & Hemat Daya

Dibangun di atas fondasi Tauri 2.0 dan Rust, tanpa bloatware Electron yang rakus memori.

Spotify SMTC Real-Time

Membaca sesi pemutaran Windows secara native tanpa perlu token berulang. Kontrol play, pause, dan ganti lagu langsung dari kapsul.

Sinkronisasi Lirik LRCLIB

Menampilkan lirik berjalan otomatis baris demi baris, bersih dari script berbahaya dan ter-render mulus di layar.

Ringan: Hanya 3.84 MB

Ukuran unduhan installer hanya 3.84 MB dengan konsumsi RAM di bawah 50 MB, aman dijalankan bersamaan dengan game berat.

Keamanan Teruji (68/69 Bersih)

Kebijakan CSP ketat, zero telemetry mencurigakan, dan 68 dari 69 vendor keamanan VirusTotal memvalidasi biner bersih.
